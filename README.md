**🌱 Plant Leaf Disease Detection System**

**📌 Overview**

Plant health plays a critical role in agriculture and food production. Early and accurate detection of plant diseases helps farmers take timely action, preventing crop loss and improving yield.
This **Plant Leaf Disease Detection System** uses Deep Learning to classify leaf images into 39 different categories. It leverages a Convolutional Neural Network (CNN) trained on the **PlantVillage dataset** to identify diseases from plant leaf images with high accuracy.

**🚀 Features**

🌿 Detects 39 different plant diseases and healthy leaves.

📸 Accepts leaf images for real-time classification.

🧠 CNN model built with PyTorch for high accuracy.

🌍 Frontend built with Angular for a responsive and user-friendly interface.

⚙️ Backend APIs using Spring Boot and Flask (Python) for model integration.

📊 Pre-trained on PlantVillage Dataset for robust performance.

🔄 Easy deployment and integration with web applications.

**⚙️ Installation & Usage**

**1️⃣ Clone Repository**

git clone https://github.com/Sadanand87/Plant-Leaf-Disease-Detection-System.git

cd Plant-Leaf-Disease-Detection-System

**2️⃣ Setup Backend (Flask API for Model)**

cd backend/flask-api
pip install -r requirements.txt
python app.py

**3️⃣ Setup Backend (Spring Boot)**

cd backend/springboot
mvn spring-boot:run

**4️⃣ Setup Frontend (Angular)**
cd frontend/angular-app
npm install
ng serve
